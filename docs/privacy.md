# 模板内容边界

模板由文件白名单提取通用组件和基础样式，重新编写站点配置与示例内容。没有复制原始 Git 历史或原网站内容目录。

## 排除项

- 原站文章、照片、经历、简历、二维码、联系方式和备案信息。
- 原始搜索索引、Feed、媒体产物、部署日志和临时附件。
- 原站环境文件、凭证、私有后台、数据库与服务配置。
- 绑定具体项目的应用与第三方业务内容。

## 主动公开的信息

Neo 署名、模板仓库地址、演示地址和许可证版权信息用于公开标识来源。GitHub Pages 工作流是此模板新建的部署配置，不沿用原站配置。

所有演示文章、项目和经历是虚构数据。几何图形为此模板新建，不含照片元数据。

## 扫描范围

scripts/check-privacy.mjs 扫描源码与 dist，检查非示例邮箱、私有网络地址、常见凭证、机器路径与禁止文件。唯一允许的工作流为 .github/workflows/pages.yml。规则只报告路径和名称，不回显可能的凭证。

根目录的 node_modules、.git 和 artifacts 不作为发布内容扫描；dist 中生成的第三方完整许可证包含依赖作者的公开署名，由构建脚本从依赖包复制，单独检查来源。发布候选文件还应通过 Git 暂存区检查，确认没有把这些忽略目录加入版本控制。

字符串检查无法识别所有隐私。公开前仍需人工检查文本、图片、元数据、外链和依赖许可证。
