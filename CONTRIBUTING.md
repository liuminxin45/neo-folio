# Contributing

Use Node.js 24+ and the pnpm version declared in package.json. Install with pnpm install --frozen-lockfile.

Before submitting a change, run pnpm lint, pnpm test, pnpm build, and pnpm check:privacy. Check both root-path and repository-subpath builds when changing navigation or asset paths. Add meaningful regression coverage for behavior changes.

Do not contribute private documents, personal data, credentials, generated media from another site, or local deployment settings. Use fictional examples and assets you have permission to redistribute.

Contributions to covered code are subject to CPAL-1.0. Preserve attribution, license notices, and corresponding-source obligations. Document changes and their date in CHANGELOG.md. Third-party code retains its own license.
